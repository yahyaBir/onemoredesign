# Sample 3D model

`water-bottle-sample.glb` is the Water Bottle sample model from KhronosGroup's
[glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/WaterBottle).
The model is released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

This is a demo asset for the Ecopak X Vision project card, not the Ecopak product model.
